# แบบประเมินความพึงพอใจ หน่วยรับบริจาคเลือดเคลื่อนที่ศิริราช ปีงบประมาณ 2570

- แบบสอบถาม (ผู้บริจาค): https://nuttawit61.github.io/Mobileunitsurvey/
- Dashboard (อาจารย์และเจ้าหน้าที่ ต้องใส่รหัสผ่าน): https://nuttawit61.github.io/Mobileunitsurvey/dashboard.html

ลิงก์แยกตามสถานที่ (ใช้ทำ QR Code): https://nuttawit61.github.io/Mobileunitsurvey/?site=ชื่อสถานที่

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแบบสอบถาม — ส่งคำตอบไป Apps Script แล้วบันทึกลง Google Sheet |
| `dashboard.html` | หน้า Dashboard — เข้าสู่ระบบด้วยรหัสผ่าน แล้วดึงข้อมูลจาก Apps Script |

ข้อมูลคำตอบเก็บใน Google Sheet เท่านั้น repository นี้ไม่มีข้อมูลผู้ตอบ ไม่มีรหัสผ่าน และไม่มีลิงก์ชีต
โค้ดฝั่ง Google (Apps Script) เก็บแยกไว้ในเครื่อง ไม่ได้อยู่ใน repository นี้
