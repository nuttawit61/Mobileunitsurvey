## ลิงก์แบบสอบถามแยกตามสถานที่ (แนะนำ)

ต่อท้ายลิงก์ด้วย `?site=ชื่อสถานที่` ระบบจะเติมชื่อสถานที่และวันที่วันนี้ให้อัตโนมัติ ผู้บริจาคไม่ต้องพิมพ์เอง และชื่อสถานที่จะตรงกันทุกคน (Dashboard จัดกลุ่มตามชื่อที่พิมพ์ ถ้าพิมพ์ต่างกันจะแยกเป็นคนละสถานที่)

```
https://nuttawit61.github.io/Mobileunitsurvey/?site=บริษัท ปตท. จำกัด (มหาชน)
```

นำลิงก์นี้ไปสร้าง QR Code ของแต่ละวันที่ออกหน่วย ผู้ตอบยังแก้ชื่อสถานที่ได้ถ้าไม่ถูกต้อง

## ติดตั้ง

### 1. แบบสอบถาม
1. ใช้ Google Sheet ของหน่วยเคลื่อนที่ (แยกจากของในสถานที่) > **ส่วนขยาย > Apps Script** > วาง `Code.gs`
2. รัน `setupSurvey` หนึ่งครั้ง (สร้างแท็บ **คำตอบหน่วยเคลื่อนที่ 2570**)
3. **การทำให้ใช้งานได้ > เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. นำลิงก์ `/exec` ไปใส่ที่ `const WEB_APP_URL` ใน `index.html`

### 2. Dashboard
1. script.google.com > **โปรเจกต์ใหม่** (ไม่ใช่ในชีต) > วาง `dashboard-apps-script.gs` > แก้ `SPREADSHEET_URL` เป็นลิงก์ชีตหน่วยเคลื่อนที่
2. ⚙️ **การตั้งค่าโปรเจกต์ > คุณสมบัติของสคริปต์** > เพิ่ม `DASHBOARD_PASSWORD` = รหัสผ่าน
3. รัน `testConnection` > อนุญาต
4. **การทำให้ใช้งานได้ > เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. นำลิงก์ `/exec` ไปใส่ที่ `const DASHBOARD_API_URL` ใน `dashboard.html`

> ไฟล์ `.gs` ที่ใส่ลิงก์ชีตแล้ว ให้วางใน Apps Script เท่านั้น ห้ามอัปขึ้น GitHub

## Dashboard

| เมนู | ใช้ทำอะไร |
|---|---|
| 📊 **ภาพรวม** | ตัวชี้วัด กราฟรายวัน ตารางสีจุดบริการ **คะแนนรายสถานที่** และ **รายงานรายวันพร้อมรายชื่อสถานที่ที่ออกหน่วย** |
| 📅 **ปฏิทิน** | ปฏิทินรายเดือน แต่ละวันแสดงคะแนนเฉลี่ย (หรือ % คะแนนรวม > 4) จำนวนผู้ตอบ และสถานที่ · คลิกวันเพื่อดูคะแนนแยกตามสถานที่ |
| 📋 **ข้อมูลดิบ** | 1 แถว = ผู้ตอบ 1 คน มีคอลัมน์สถานที่ ค้นหา เรียง แบ่งหน้า ดาวน์โหลด CSV |
| 💬 **ความคิดเห็น** | ข้อความจากผู้ตอบ พร้อมสถานที่ กรองตามหัวข้อ ค้นหาคำ ดาวน์โหลด CSV |

กรองตามสถานที่ / ช่วงอายุ / ประสบการณ์ได้ทุกเมนู · คลิกชื่อสถานที่ที่ใดก็ได้เพื่อกรองเฉพาะสถานที่นั้น

**ตัวชี้วัด:** คะแนนเฉลี่ยภาพรวม (24 ข้อ) · ร้อยละผู้ตอบที่คะแนนเฉลี่ยของตนเอง **มากกว่า 4.00** · นับวันตาม **วันที่บริจาค** ที่ผู้ตอบระบุ

**Login:** รหัสผ่านตั้งใน `DASHBOARD_PASSWORD` (แก้แล้วมีผลทันที) · ผิดรวม 10 ครั้ง ล็อก 10 นาที · จำการเข้าสู่ระบบ 6 ชั่วโมงหรือจนปิดแท็บ

เมื่อแก้โค้ดใน Apps Script: **จัดการการทำให้ใช้งานได้ > ✏️ > เวอร์ชันใหม่** (ลิงก์ `/exec` เดิมใช้ต่อได้)
